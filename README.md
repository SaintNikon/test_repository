# Никонов Сергей. Проект спринта 6: 
Создан класс `DataFrameReporter` для первичной диагностики данных. У данного класса есть метод `show_report` для вывода стандартного отчета.

 На вход класс принимает 3 формата:
 - `float_format` — формат вывода на экран чисел с плавающей точкой. Значение по умолчанию `0.05f`;
 - `percent_format` — формат вывода на экран процентов. Значение по умолчанию `0.02%`;
 - `include_all` — режим вывода информации о столбцах датафрейма. Принимает булевое значение: False — выводить информацию только о числовых столбцах датафрейма, True — выводить информацию обо всех столбцах датафрейма. Значением по умолчанию является`false`.

 Метод `show_report` принимает на вход:
 - `df` — датафрейм pandas, по которому нужно вывести отчёт;
 - `title` — строка с заголовком отчёта. Значение по умолчанию `None`, чтобы была возможность выводить заголовок только при необходимости.

## Что внутри

- `payments.csv` — пример датасета для вывода отчета;
- `reporter.py` — Код с объявлением класса  `DataFrameReporter` и его методом `show_report`;
- `main.py` — код с выводом отчета по данным `payments.csv`;
- `requirements.txt` — зависимости проекта

## Установка
